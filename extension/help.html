Using Canvas Local Archive

Back to your courses · Browser capability check

Install and update

In Helium, open helium://extensions (chrome://extensions redirects there), enable Developer mode, click Load unpacked, and choose this extension folder. In the toolbar’s Extensions menu, pin Canvas Local Archive. Its icon opens a full tab.

For updates, keep the same folder and manifest key. Finish or cancel jobs, replace source files, click Reload on the extension’s card, and reopen its tab. Removing the extension can erase remembered handles; normal Reload retains local data.

Connect, scan, select

Open Canvas in this Helium profile, finish normal Cal Poly login and MFA, then click Connect / Refresh. Authentication is checked using Canvas API data. A hostname or sign-in page is never accepted as proof. Keep the Canvas tab open when the connection uses the same-origin fallback.

Scan each course to discover content; scanning never downloads original attachments. Choose a different real folder for each course. The selected folder is the course root. Expand Modules, Assignments, and Other course files. Select all or select individual materials, then deselect anything you do not want.

Review the actual folders

Check destination inspects all discovered relative paths; Review selected items inspects the selected set and current remote metadata. Existing unindexed files and local edits are preserved by default. Verify contents compares against the current remote material. Replace this file explicitly allows an overwrite. Missing files are downloaded; verified unchanged files are skipped.

If a selected page depends on a deselected attachment, the review lists that dependency. Saved HTML keeps its online link. Files found in several modules retain those associations and may have a copy in each selected module, without an additional Other course files copy.

Reports and recovery

Keep the extension tab open during jobs. Cancel retains completed files and aborts open writers. Each course run saves a report under .canvas-archive/reports/; the checksum index is .canvas-archive/index.json. View latest report under Python index and reports. If saving the report fails, it remains in browser storage and Save report again retries the folder write.

After a closed tab, crash, or permission loss, reconnect, renew folder access, restore the last selection, and recheck. Recovery verifies actual disk contents. A newly-created empty placeholder can remain after interruption; it is unverified and requires explicit verification or replacement. The extension never deletes your notes or old materials.

Limits and troubleshooting

Only accessible course materials are archived. External sites and tools remain links. Quiz questions, submissions, replies, grades, and personal account files are outside the scan. A denied Files endpoint does not stop accessible module discovery; coverage limitations are reported.

Signed file hosting URLs may require additional HTTPS host access or may fail because of CORS. Grant only the file’s actual hosting origin; this does not change the Canvas API origin. If folder picking fails, run the capability check in your normal visible tab. Browser policies or the Linux desktop portal may prevent folder access. No native helper is installed.

See the project’s README.md and docs/VERIFICATION.md for complete installation, development, testing, and known limitations.
